# MCP Proxy

**Transport-aware proxy** for connecting to MCP servers
- **Client ↔ Proxy**: HTTP/JSON-RPC (internal)
- **Proxy ↔ MCP Server**: SSE (web-standard)
- **Multi-server routing** with authentication
