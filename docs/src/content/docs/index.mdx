This site documents the **observability** crates in the [`promptfleet-agents`](https://github.com/promptfleet/promptfleet-agents) repository. Other workspace members (SDK, A2A, LLM) are covered in crate `README.md` files and `cargo doc` until more guides are added.

**Repository:** [github.com/promptfleet/promptfleet-agents](https://github.com/promptfleet/promptfleet-agents)

**Full API reference:** run `cargo doc --open` in the repo (per-crate: `cargo doc -p <crate> --no-deps`).
